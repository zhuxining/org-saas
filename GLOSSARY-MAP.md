# Glossary Map

Engineering skills should read the glossary relevant to the task. This repository currently has one shared domain glossary; it covers the vocabulary used across the applications and shared packages.

| Context                                 | Glossary                                                       | Scope                                                                                                                                                              |
| --------------------------------------- | -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Shared platform and organization domain | [docs/architecture/GLOSSARY.md](docs/architecture/GLOSSARY.md) | Users, organizations, personal and organization workspaces, membership, roles, permissions, teams, and organization lifecycle concepts shared across the monorepo. |

Keep shared concepts in the existing glossary. Add a context-specific `GLOSSARY.md` and update this map only when that context has distinct vocabulary that should not be merged into the shared language.
