# 审计记录

## 记录范围

组织审计记录覆盖组织创建和设置、所有权转让、成员与邀请、团队及角色管理、归档和恢复。平台审计记录覆盖封禁、解除封禁及撤销用户会话。失败操作不生成记录。

记录保存操作者 ID 与名称、动作、目标类型与 ID、发生时间及少量字段级摘要。邀请邮箱、封禁原因、会话令牌和其他认证凭证不写入摘要。记录仅通过业务服务追加；没有面向用户的修改或删除接口。

## 查询权限

组织 owner、admin 和被明确授予 `audit.read` 的自定义角色可查询本组织记录。平台管理员可查询平台管理记录；平台管理员身份不会授予组织审计权限。查询结果只包含发生时间距今不超过 180 天的记录。

## 保留与清理

过期记录可通过仓库根目录命令分批清理：

```sh
vp run audit:prune
```

部署环境应将该命令配置为每日维护任务。它只删除发生时间早于 180 天保留期限的审计记录，不修改其他数据。部署目标明确后，将该命令接入目标环境的调度器。
