# 多组织 SaaS 领域词汇

本词汇表定义平台、组织及组织内协作与授权的共同语言。

## Language

**用户（User）**：
平台上的一个登录身份，可以加入多个组织。
_Avoid_：将用户与组织成员混称

**组织（Organization）**：
平台中独立管理成员、角色及业务数据的单位。
_Avoid_：将团队称为组织

**个人空间（Personal Space）**：
用户管理自身资料、个人记录和组织入口的空间，进入组织后仍保留同一用户的个人身份。
_Avoid_：组织工作空间、仅指统计面板的 Dashboard

**组织工作空间（Organization Workspace）**：
组织成员在目标组织身份与权限范围内参与业务和管理的空间；切换工作空间不更换登录账号。
_Avoid_：第二套账号

**个人收藏（Personal Saved Item）**：
用户保存某个资源引用的个人记录，切换组织不改变其归属；收藏记录不赋予被引用资源的访问资格。
_Avoid_：组织共享收藏

**组织成员（Organization Member）**：
用户加入某个组织后形成的身份；同一用户在不同组织具有独立的成员身份。
_Avoid_：将组织成员与平台用户混称

**组织所有者（Owner）**：
对所属组织具有所有权的组织成员；一个组织可有多个同等所有权的所有者，始终至少保留一个。
_Avoid_：平台管理员、团队负责人

**组织归档（Organization Archive）**：
保留组织及其数据、停止普通业务访问的可恢复状态；组织所有者可查看归档状态并恢复组织。
_Avoid_：删除组织、注销组织

**平台角色（Platform Role）**：
规定用户在整个平台范围内可执行操作的角色，与其组织角色分别表达。
_Avoid_：未说明范围的“管理员角色”

**组织角色（Organization Role）**：
规定组织成员在所属组织内可执行操作的一组权限，可以是平台预置角色或本组织的自定义角色。
_Avoid_：将组织角色与平台角色混称

**预置组织角色（Predefined Organization Role）**：
平台统一提供、供各组织使用的组织角色。
_Avoid_：平台角色（当实际指预置组织角色时）

**自定义组织角色（Custom Organization Role）**：
组织获授权的管理者创建、仅供该组织使用的组织角色；可以自行组合权限，也可以由预置组织角色复制而来，复制后的角色与原角色独立维护。
_Avoid_：全局角色

**团队（Team）**：
组织内用于成员分组与协作的集合；一个组织成员可以加入多个团队，加入团队本身不自动授予操作权限。
_Avoid_：部门（当实际仅指协作分组时）

**操作权限（Action Permission）**：
执行某类资源上的特定操作的资格，例如邀请成员或修改任务。
_Avoid_：数据范围（当实际指允许执行的操作时）

**数据范围（Data Scope）**：
用户可访问或操作的具体业务记录集合，需与操作权限共同决定一次业务访问是否允许。
_Avoid_：操作权限（当实际指允许访问的记录时）
