# 测试规范

## 准入标准

默认通过类型检查、lint、构建及必要的交互检查验证改动。自动化测试仅用于验证明确的业务风险或复现已知缺陷；用户明确要求测试时，也应围绕具体行为编写。

新增或修改测试前，说明它防止的实际问题、触发条件和预期结果。用例名称应表达业务行为，断言用户可观察的结果、访问资格或最终数据状态。无法说明失败会造成什么业务后果的用例不纳入测试集。

不按单元、接口、集成等技术层级要求补齐测试，也不以覆盖率或测试数量作为交付目标。选择能真实验证风险的最小执行范围；函数调用、服务端入口或浏览器操作都可以作为手段。

## 禁止的内容

- 对每个函数、组件或接口机械生成用例，或为覆盖率凑测试。
- 在测试中复制实现逻辑，再用同一逻辑计算预期值。
- 仅断言 mock 调用次数、内部执行顺序或私有结构，缺少业务结果断言。
- 验证框架、第三方库自身行为，或仅确认静态配置与实现逐项一致。
- 用 mock 替代正在验证的权限检查、事务或组织隔离逻辑，使业务缺陷无法触发失败。

允许为具体故障注入失败，但必须断言业务后果，例如失败后所有权未变更、写入已回滚。权限测试应表达具体的允许或拒绝场景，不能只复述权限配置。

## 文件与依赖

- 所有测试文件、测试数据和测试辅助代码集中放在仓库根目录 `tests/`，按业务场景分目录，不放在应用或包的源码目录。Playwright 的浏览器流程集中放在 `tests/browser/`，与服务端行为测试使用不同运行器。
- 测试文件统一使用 `*.test.ts` 或 `*.test.tsx`；仅依赖 PostgreSQL 的测试使用 `*.postgres.test.ts` 或 `*.postgres.test.tsx`。共用辅助代码按实际复用需要放在 `tests/helpers/`，数据放在 `tests/fixtures/`。
- 共享包通过 `@org-saas/*` 的公开 exports 导入。应用没有公开 exports 的独立工具可使用指向应用源码的相对导入，不为测试扩大生产接口。
- 测试代码遵守仓库的严格类型及 lint 约束。测试运行范围以根 `vite.config.ts` 为准，测试编译配置以 `tests/tsconfig.json` 为准。

## 执行与交付

从仓库根使用 `vp test` 运行服务端与工具行为测试，按需指定 `tests/` 内的文件或业务目录；Playwright 浏览器测试使用下方独立入口。新增用例不要求运行所有无关测试；迁移或调整测试配置后，应检查全部测试文件的发现与执行结果。

依赖 PostgreSQL 的现有用例通过 `PERMISSION_TEST_DATABASE_URL` 连接已确认的隔离测试库；未设置时跳过，不能将跳过报告为通过。测试库需具备当前 schema，数据库初始化、清理或变更遵循 [DB 约定](../../packages/db/AGENTS.md)，不得使用开发、预发或生产业务数据代替测试数据。

## 浏览器功能验证

Playwright 只覆盖关键用户流程，连接真实应用服务和隔离数据库，不 mock 正在验证的登录、权限或业务请求。通过现有认证服务端 API 及 HTTP 辅助代码准备场景数据，不向浏览器注入登录凭证来绕过正在验证的登录流程。断言页面结果与刷新后的状态，不以成功提示或 HTTP 200 单独证明功能可用。

首次安装：

```sh
bun install --frozen-lockfile
bun run --cwd tests playwright install chromium
```

启动 Docker 后，从仓库根执行：

```sh
bun run test:e2e
# 只执行登录回跳流程
bun run test:e2e login-return.test.ts
# 查看最近一次 HTML 报告
bun run --cwd tests playwright show-report
```

运行入口自动创建绑定本机回环地址的临时 PostgreSQL 17 容器，在该空库应用当前 schema，构建 Web 后启动独立的生产预览服务，结束后删除容器。数据库不挂载持久化卷，账号与组织使用唯一标识。运行时覆盖应用数据库和认证环境变量，不复用开发服务；Docker 不可用或端口 4317 被占用时失败，不降级到已有环境。首次执行需下载 PostgreSQL 镜像及 Chromium。

首批浏览器场景覆盖登录回跳与退出后的访问阻断、创建组织并邀请新账号加入、两个标签页的组织数据与写入隔离，以及退出换账号后的缓存与访问隔离。

浏览器运行配置位于 `tests/playwright.config.ts`，仅使用 Chromium，串行执行，重试次数为 0。本地预览的认证请求共享 IP 限流桶：准备账号使用服务端 API，浏览器登录按当前 Better Auth 的 10 秒窗口间隔提交，不关闭生产限流或重试失败的登录。失败保留截图与 trace，HTML 报告输出到 `tests/playwright-report/`，附件输出到 `tests/test-results/`；这些目录不提交，报告仅在本地查看；浏览器测试由开发者按需执行，不配置 GitHub Actions。

交付记录实际执行的检查、通过与跳过数量，以及尚未验证的业务风险。修改现有测试时核对其业务目的；仅在风险消失、已有等价覆盖或测试不符合准入标准时删除，并说明依据。
