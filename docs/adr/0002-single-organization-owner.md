# 每个组织仅有一个所有者

每个组织始终恰有一个 owner，不支持共同所有权；所有权变更只能通过一个原子转让操作，将新成员设为 owner 并在同一操作中为原 owner 指定非 owner 角色。单一所有权让组织管理权边界明确；普通成员、邀请、退出、移除和角色更新入口不得绕过转让操作，转让与并发成员变更必须由服务端以原子机制保证。

## 实施约束

Better Auth 1.7.7 的 HTTP handler 会在请求内重新绑定基础 adapter，因此事务必须跨越该重绑定继续生效。认证包使用事务感知 adapter 代理，并在 owner 敏感写入前锁定组织版本行；HTTP 与 `auth.api.*` 写操作在同一事务内执行检查和提交。已有零个或多个 owner 的组织保持原样，owner 敏感操作 fail closed，等待显式数据审查，不自动选择或降级 owner。
